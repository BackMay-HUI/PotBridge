# PotBridge v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 扩大可播放范围，优先修复 Bilibili 分轨媒体，增加通用 DASH/HTTP-FLV，交付有实测证据的 0.2.0。

**Architecture:** 保留 Edge MV3 + Go Native Messaging。结构化轨道经来源验证后转交本地 relay；B 站使用 PotPlayer /aud，MPD 重写后由播放器解码，FLV 直接中转。

**Tech Stack:** TypeScript、Go、现有 Node 测试/happy-dom、Windows PotPlayer；不新增 FFmpeg 运行依赖。

**Spec:** docs/superpowers/specs/2026-10-25-potbridge-v02-design.md

## Global Constraints

- 版本 0.2.0，Native Messaging 协议 2；同步扩展、host、测试和文档。
- 保留现有 MP4/HLS 行为、560×600 弹窗、本机安装位置和用户设置。
- 不捕获账户 Authorization；网页不能提供可信媒体头、启动程序或改配置。
- 上游地址仍执行准确来源头隔离和私网/DNS/重定向校验。
- 不引入 FFmpeg 运行依赖；DASH/FLV 不支持结构明确报错。
- 有界候选/清单/轨道及资源映射，错误和诊断不得暴露签名 URL 或令牌。

## Review Focus

- B 站初始数据与 SPA 切换并发返回，候选必须仍属于当前视频/分 P。
- 多清晰度/多编码、音轨缺失或不可达，不能把静音视频误标为完整成功。
- MPD 相对路径、模板数字、绝对 URL、跨来源和签名查询不能造成错误映射或绕过网络限制。
- FLV 长连接预检必须快速返回，不能等待整场直播下载结束。
- 关闭弹窗、切页、停止、host 断线和协议不匹配时各轨会话必须同步清理。
