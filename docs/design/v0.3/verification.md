## 状态检查

| 示例状态 | 显示 | 播放按钮 |
| --- | --- | --- |
| ready | 音视频已就绪 | 可用 |
| empty | 等待发现媒体 | 不可用 |
| offline | 本机组件尚未连接 | 不可用 |
| missing | 尚未获得音轨 | 所选来源缺音轨时不可用；切为完整的 720P 来源后恢复 |
| error | 媒体地址暂时无法访问 | 可重试 |
| disabled | 此站点尚未启用检测 | 不可用 |

模拟检查 / 发送后显示“已发送到 PotPlayer”，并提示实际音画仍需在播放器确认；结束中转后显示“中转已结束”。没有将网络请求或发送动作写成播放成功。
