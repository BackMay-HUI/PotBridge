# v0.1.0 验收记录

更新日期：2026-10-25。

## 实际使用反馈

用户已在自己的 Windows、Edge 和 PotPlayer 环境确认：

1. 本机组件安装后，扩展设置显示“已连接”。
2. 原始视频案例已成功播放；用户明确确认上一阶段目标已达成。

这是用户提供的实际运行结果。工具无法打开扩展内部页面，因此没有将它表述为工具独立观察的端到端验收，也没有据此推断所有网站均可播放。

## 已修复的安装问题

某些打包应用内启动的 PowerShell 会将 AppData 文件写入应用私有目录，但注册表仍指向标准目录，导致 Edge 报 `NATIVE_HOST_NOT_FOUND`。安装脚本现使用文件句柄核对物理路径；发生重定向时，在写入注册表前停止并提示从 Windows 开始菜单打开 PowerShell。用户按此流程安装后已确认连接成功。

## 验证边界

- 尚未独立记录原始视频连续播放 10 分钟、拖动和切集的完整实测结果。
- 真实直播平台的长时间解码、到期地址恢复和各类代理环境没有全量兼容性验收。
- 直播持续性测试使用合成 TS 数据，只证明传输与清理行为；不证明画面、声音或编码兼容性。此前中止的 900 秒测试不计为通过。
- DASH、低延迟 HLS、SAMPLE-AES/DRM 等明确不支持的格式，详见 README。

后续手动回归建议：安装后刷新目标网页并正常播放 → 检测和诊断 → 发送 PotPlayer → 确认画面、声音、音轨 → 连续播放 → 拖动 → 切集 → 关闭弹窗确认继续播放 → 结束中转。发现问题时导出脱敏诊断并记录播放器错误全文。
