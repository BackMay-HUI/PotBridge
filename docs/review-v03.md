## 发现与处理

作者用 `an external save after a local write commits but before acknowledgement reconciles when writes drain` 复现 Forest / Mica 不一致，测试先失败。修复为写入队列排空后重新读取权威 appearance，并以 revision 与待写数量校验读取是否仍有效。另用 `a late reconciliation read cannot undo a newer cross-page change` 验证迟到的核对结果不能覆盖较新更新；移除保护时失败，恢复后通过。修复后的完整扩展测试为 87 / 87，TypeScript 检查通过。
