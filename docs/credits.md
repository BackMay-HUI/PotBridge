# 主题与素材说明

PotBridge 五主题的界面、配色组合与几何装饰随项目源码提供。Apple、Fluent/WinUI 和 P3R 是设计参考；没有打包其官方 UI 截图、商标图像或游戏素材。

月下礼仪使用樱小路露娜同人立绘。角色与原作品属于原权利人，项目不主张角色权利，也不是官方产品。人物辨识参考为 [Navel 官方角色页](https://project-navel.com/tsukiniyorisou/chara01_luna.html)；本包内的图像由 imagegen 生成，未打包该页面的官方原图。

生成原图、优化 WebP 和完整提示词保存在公开仓库的 [设计素材目录](https://github.com/BackMay-HUI/PotBridge/tree/main/docs/design/v0.3/assets)。正式扩展仅打包 318,606 字节的 WebP。图像在界面内作为装饰，不遮挡操作，不需要网络请求。
