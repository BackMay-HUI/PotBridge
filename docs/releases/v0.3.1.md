PotBridge · 映桥 v0.3.1 修复 v0.3.0 工具栏弹窗被压成竖条的问题，保留五款主题和全部媒体功能。

### 修复内容

v0.3.0 的弹窗使用视口宽度限制自身宽度。Edge 根据页面内容自动计算工具栏弹窗尺寸时，页面可能跟随初始窄视口持续收缩。v0.3.1 将根文档、body 和主容器固定为 560 × 600，避免这一尺寸依赖。

实际浏览器回归中，修复前页面在小视口下收缩到 240px；修复后根文档、主体和操作区均为 560px、主区域高 600px。五主题尺寸一致，菜单切换和 Escape 焦点返回正常。该小视口测试是布局回归，真实 Edge 工具栏验证另按用户反馈记录。

用户更新修复版并绑定当前扩展 ID 后，已明确确认「已连接，完整显示，换肤与播放正常」。87 项扩展测试、Go 竞态与静态检查、生产构建和发行包校验通过。实测是代表性环境，不保证所有 DPI、屏幕、媒体和网络环境。

### 更新

将本包 `extension` 的内容更新到原来加载的固定目录，在 Edge 扩展管理页点击重新加载。确认版本为 **0.3.1**，重新点击工具栏图标。若需要验证媒体检测，刷新视频网页一次。

无需为此修复重装本机组件；v0.2 / v0.3.0 的协议 2 组件可继续使用。保持原目录可以保留扩展 ID、播放器路径、主题和站点设置。

包内提供 Windows x64 本机组件、README、验收及审查说明；ZIP 附 SHA256。原有媒体、编码和网络支持边界不变。
