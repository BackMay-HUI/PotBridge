PotBridge · 映桥 v0.3 将五款可切换主题接入正式 Edge 扩展：月下礼仪（樱小路露娜）、瓷白、深蓝时刻、云母、墨绿。弹窗和设置页共用操作布局，各自拥有字体、配色、材质与装饰。

### 本版变化

- 弹窗右上角调色板快速切换，设置页五张主题卡片即时应用；默认露娜，标题区配有同人立绘。
- 主题独立自动保存，已打开的弹窗和设置页同步，重新打开保留选择；不提交播放器、代理或站点设置。
- 保留当前媒体选择、未保存的配置和焦点；处理迟到读取、快速连续切换、未知主题与存储失败。
- 修复媒体列表刷新和单选切换丢失键盘焦点；保留清晰的忙碌、离线、缺音轨和错误反馈。
- 保留现有 MP4、HLS、Bilibili 分轨、DASH、HTTP-FLV、诊断与结束中转功能。没有增加运行时依赖、浏览器权限或远程资源。

### 安装与升级

需要 Windows x64、Edge 120+ 和 PotPlayer。下载并完整解压 ZIP。新用户在 Edge 开启开发人员模式并加载 `extension`，再按 README 运行安装脚本绑定当前扩展 ID。

**v0.2 用户无需为主题重装本机组件。** 先结束中转，将本版 `extension` 内的内容更新到原先加载的固定目录，在 Edge 扩展管理页点击重新加载，再刷新视频网页一次。保持同目录可保留扩展 ID、播放器路径和站点开关。若移动目录导致 ID 改变，仍须重新绑定。

协议继续为 2，包内本机组件版本为 0.3.0，已安装的 v0.2 组件也可使用。v0.1 用户须同时升级本机组件。

### 验证与边界

扩展测试覆盖真实生产 HTML/控制器、主题同步与并发、保存和发送的隔离、原有媒体处理及实际 Windows EXE。发布包校验覆盖早期主题脚本、HTML/CSS 本地资源、立绘和 ZIP SHA256。详见仓库 `docs/release-check.md` 和 `docs/acceptance.md`。

本轮浏览器验收工具因无法可靠确认 Windows 当前浏览器 URL 而中止，未将本轮正式页面的视觉或 Edge/PotPlayer 解码复测标记为通过。此前 v0.2 的用户播放确认保留为历史证据；五主题设计稿的视觉检查也不冒充正式扩展验收。

露娜为生成的同人立绘，来源见 `docs/credits.md`。云母为网页材质模拟。DRM、WebRTC、WebSocket-FLV 等原有支持边界不变；扩展尚未上架 Edge 商店，安装包无数字签名。ZIP 附独立 SHA256 校验文件。
