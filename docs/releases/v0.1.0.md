PotBridge · 映桥的首个个人使用版本：在 Microsoft Edge 发现网页 MP4 / HLS 点播和直播，通过 Windows 本机中转交给 PotPlayer 播放。

### 安装

1. 下载并完整解压 `PotBridge-0.1.0-windows-x64.zip`。
2. 在 Edge 扩展管理页开启开发人员模式，加载包内 `extension` 目录，复制扩展 ID。
3. 从 Windows 开始菜单打开 PowerShell，进入解压目录运行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-host.ps1 -ExtensionId "替换为实际扩展ID"
   ```

4. 在扩展设置检查连接，填写自己的 PotPlayer 路径；刷新目标网页并先播放，再从扩展发送。

需要 Windows x64、Edge 120+ 和 PotPlayer。普通使用无需 Node/Go。更新前结束中转并关闭播放器，替换扩展文件后重新加载，再重新安装本机组件。ZIP 旁提供 SHA256，包内 README 包含完整升级、排错、隐私及卸载说明。

### 本版功能与修复

- MP4 / HLS、独立音轨、AES-128 identity、初始化片段和 Range 请求。
- 站点开关、媒体诊断、脱敏导出、系统/PAC/直连/手动代理。
- cycani 当前页面同集地址刷新。
- 560 × 600 px 弹窗，放大文字并固定播放按钮。
- 防止发送期间切页遗留会话；保护各音视频清单窗口，超限清单明确报错。
- 检测安装时 AppData 重定向，改善本机组件连接排错。

用户已确认真实环境中的本机连接和原始案例播放成功。自动化与发布检查详见仓库 `docs/release-check.md`。

### 支持范围

DASH、低延迟 HLS、SAMPLE-AES/DRM 尚不支持。每份 HLS 清单上限 2 MiB，当前会话的资源映射总量上限 8192（另加根地址）。传输测试不保证所有网站或编码均能解码；真实平台长时间直播仍需按使用环境验证。安装包没有数字签名，扩展尚未上架 Edge 商店。
