PotBridge · 映桥 v0.2 扩大网页视频和直播覆盖：新增 Bilibili 音视频分轨、通用 DASH MPD 和 HTTP-FLV，保留原有 MP4 / HLS。继续采用轻量 Go 本机中转，无需新增 FFmpeg 运行依赖。

### 本版变化

- B 站按清晰度和编码展示视频与音频，默认优先 AVC + AAC，通过 PotPlayer 外部音轨同时播放音画。
- 支持 B 站页面内切换视频和分 P，核对当前内容身份后恢复已捕获或预取的来源。
- 支持网页返回的 HTTP-FLV 直播和通用 DASH 清单、分片与 Range；DASH 常见 BaseURL、SegmentBase/List/Template/Timeline 及动态刷新受支持。
- 修复部分 B 站 CDN 返回 567、旧音轨更新丢失、DASH 清单被媒体片段挤到末尾、停止期间迟到播放和旧会话清理影响新播放的问题。
- 分轨候选显示画质、视频/音频编码和缺音轨提示；沿用 560 × 600 px 弹窗。

### 安装与升级

需要 Windows x64、Edge 120+ 和已安装的 PotPlayer。完整解压 ZIP，在 Edge 扩展管理页开启开发人员模式，加载 `extension` 文件夹，复制当前扩展 ID。从 Windows 开始菜单打开 PowerShell，在解压目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-host.ps1 -ExtensionId "替换为实际扩展ID"
```

自动查找不到播放器时，在扩展设置填写其 EXE 完整路径。检查连接后刷新视频网页，并先让网页正常播放，再检测和发送。

**v0.1 用户须同时升级扩展和本机组件。** 本版使用协议 2，旧组件会提示 `VERSION_MISMATCH`。先结束中转、关闭播放器，将新版扩展内容更新到原来的固定目录，重新加载后刷新已打开的视频页面一次，再运行新版安装脚本。播放器路径、代理和原有站点开关会保留；如果改动目录导致扩展 ID 改变，请使用新 ID 安装。

### 验证与边界

73 项扩展测试、实际 Windows EXE 协议检查、完整 Go 并发检查、安装准备及包哈希检查通过。60 秒合成 HLS 测试覆盖传输恢复和停止。用户实测确认 B 站普通视频音画和拖动、无刷新切换、FLV 直播和代表性 DASH 音画与拖动正常。完整证据及审查限制见仓库 `docs/acceptance.md`、`docs/release-check.md` 和 `docs/review-v02.md`。

只使用网页已返回的授权媒体信息。DRM、低延迟 HLS、WebRTC、WebSocket-FLV、DASH 同层多 BaseURL 及部分扩展尚不支持；不保证所有站点、编码和网络环境。关闭插件弹窗或来源标签页后，已建立的播放仍继续；点击“结束中转”可停止。扩展尚未上架 Edge 商店，安装包没有数字签名。ZIP 附 SHA256 校验文件。
