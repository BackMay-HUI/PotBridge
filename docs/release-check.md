浏览器验证限制：v0.3.0 发布前的 Windows UI 检查被工具中止，随后用户报告真实工具栏弹窗收缩。v0.3.1 在后续轮次中通过普通 localhost 页面完成渲染器尺寸的失败与通过检查，未使用 Windows UI 绕过停止；实际 Edge 工具栏与播放复测按用户反馈单独记录。测试中的 Chrome 和本机边界是受控替身，不能代替真实扩展或播放器解码。详见 [验收记录](acceptance.md)。

Node 测试工具使用 `stripTypeScriptTypes`，会显示实验特性提示；没有将该提示隐藏或计为失败。安装包尚无数字签名，扩展未上架 Edge 商店。
